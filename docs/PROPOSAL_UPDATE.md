# Proposal Update

Replacement text to reposition the Catalyst proposal as an **end-user game
upgraded with Cardano on-chain identity and verifiable achievements** — not a
developer tool / builder pathway.

## Positioning

> A playable Godot game where players complete quests, build persistent
> progression, and receive verifiable Cardano-based identity and achievement
> attestations.

## Product & problem

> **Problem:** players and game studios lack a fun, real example of a game that
> uses Cardano identity and verifiable achievements without sacrificing
> gameplay.
>
> **Solution:** LAB3 ships a playable Godot dungeon-quest game. Players complete
> quests, earn XP and persistent progression, and at meaningful milestones the
> game issues a **Cardano identity/achievement attestation** — anchored on-chain
> and verified. Full CIP-0170 on-chain identity is the new integration this grant
> funds.
>
> **Target users:** game players, Web3 gamers, and community players first.
> Developers are a secondary audience (the game is open source as a reference).

## Integration (CIP-0170) — "How far along"

> TRL 5 — a working attestation layer (player profile → wallet → milestone →
> signed attestation → on-chain anchor → verification) is implemented and
> validated on Cardano Preprod. The grant carries this to **full CIP-0170
> compliance and mainnet** (TRL 7) at Milestone 1.
>
> Evidence: repo https://github.com/dmt041104111003/lab3-godot-cardano-testnet ·
> live game https://dmt041104111003.github.io/lab3-godot-cardano-testnet/ ·
> Preprod transactions in docs/evidence.
