# Assets

Runtime graphics are selected from the local asset library supplied with the
project and copied into `local_pack/`. The current art direction uses one coherent
top-down ruins pack for characters, enemies, terrain, vegetation, props and VFX,
plus its matching UI artwork.

The full source library remains in `/assets` and is intentionally ignored by Git;
only optimized runtime selections are included in the Godot export. Press Start 2P
remains the UI typeface under the SIL Open Font License 1.1.
